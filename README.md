# UPVC Design

تطبيق ويب عربي (RTL) لتصميم نوافذ وأبواب uPVC وحساب تكلفة الخامات — وحسابات الشركة — مبني على Next.js 16 و React 19.

البرنامج لـ **شركة واحدة فقط** (وليس منصة متعددة الشركات).

## البدء السريع

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## الأقسام الرئيسية

| القسم | المسار | الوصف |
|-------|--------|-------|
| الورشة | `/` | قيد التنفيذ + قائمة الانتظار |
| الطلبات | `/orders` | العملاء · المقايسات · أحدث المشاريع · طلب جديد |
| الحسابات | `/accounting` | استلام الدفعات · سجل مصروفات |
| الخامات | `/materials` | قطاعات · اكسسوار · زجاج · سلك · حديد |

القاعدة: سجّل الدفعة في الحسابات وحدّد المشروع. إن وُجدت فلوس على المشروع يدخل الورشة — وإلا يبقى مقايسة فقط.

بيانات الشركة من **الإعدادات → بيانات الشركة** أو من داخل الحسابات.

## هيكل المشروع

```
app/           صفحات Next.js (App Router)
components/
  layout/      AppShell، Header، BottomNav
  design/      قائمة البنود والتمبلتات
  drawing/     محرر الرسم التفاعلي
  materials/   محررات الخامات
  customers/   العملاء والمشاريع
  orders/      متصفح الطلبات
  accounting/  التحصيل والمصروفات
  settings/    الثيم ووحدة القياس وبيانات الشركة
lib/           منطق الأعمال (حسابات، تخطيط، تخزين، محاسبة)
```

## التخزين

بيانات الورشة مشتركة عبر Neon/Postgres.

**أسهل طريقة (مُفضّلة):** من **الإعدادات → ربط Neon بسهولة** الصق Connection string من Neon على كل جهاز مرة واحدة. لا يحتاج إعدادات Vercel.

بديل للمطورين: متغير `DATABASE_URL` على السيرفر (`/api/store`).

الثيم ووحدة القياس وترتيب التمبلتات تبقى على الجهاز فقط.

### ترحيل باكب البرنامج القديم

من **الإعدادات → استيراد نسخة احتياطية** ارفع ملف `backup-*.json` القديم (فيه `clients` / `projects` / `contracts`) — يتحوّل تلقائياً لعملاء ومشاريع وفواتير ودفعات ومصروفات.

أو من الطرفية:

```bash
npm run import:legacy -- path/to/backup.json
```

يكتب `data/workshop-kv.json` (محلي). بيانات الموظفين/الإشعارات/مراحل العقود القديمة لا تُنقل لأنها غير موجودة في البرنامج الحالي.
