# UPVC Design

تطبيق ويب عربي (RTL) لتصميم نوافذ وأبواب uPVC وحساب تكلفة الخامات — وحسابات الشركة — مبني على Next.js 16 و React 19.

البرنامج لـ **شركة واحدة فقط** (مش منصة متعددة الشركات).

## البدء السريع

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## الأقسام الرئيسية

| القسم | المسار | الوصف |
|-------|--------|-------|
| الرئيسية | `/` | آخر المشاريع + طلب جديد |
| الطلبات | `/orders` | كل العملاء والمشاريع + طلب جديد |
| الحسابات | `/accounting` | فواتير · تحصيل · مصروفات |
| الخامات | `/materials` | قطاعات · اكسسوار · زجاج · سلك · حديد |

من بنود المشروع أو قائمة المشاريع: **تقرير / طباعة** — تقرير عميل فيه الرسم والتفاصيل والأسعار، جاهز للطباعة أو حفظ PDF.

بيانات الشركة من **الإعدادات → بيانات الشركة** أو من داخل الحسابات.

## هيكل المشروع

```
app/           صفحات Next.js (App Router)
components/
  layout/      AppShell، Header، BottomNav
  design/      قائمة البنود والتمبلتات
  drawing/     محرر الرسم التفاعلي
  materials/   محررات الخامات
  customers/   العملاء والمشاريع
  orders/      متصفح الطلبات
  accounting/  الفواتير والتحصيل والمصروفات
  settings/    الثيم ووحدة القياس وبيانات الشركة
lib/           منطق الأعمال (حسابات، تخطيط، تخزين، محاسبة)
```

## التخزين

البيانات تُحفظ في `localStorage` على الجهاز — لا يوجد سيرفر أو قاعدة بيانات. المفاتيح موحّدة في `lib/storage/keys.ts`.
