# دليل التنقل — UPVC Design

البرنامج لـ **شركة واحدة فقط**. الأبواب من الشريط السفلي لكل غرض واحد — دون تكرار.

---

## الأبواب

| الباب | ماذا يفعل؟ |
|-------|------------|
| **الرئيسية** | ملخص اليوم والاختصارات |
| **الطلبات** | العملاء · المقايسات · أحدث المشاريع · طلب جديد |
| **الورشة** | الشغل اليوم: قيد التنفيذ + قائمة الانتظار + التسليم |
| **الحسابات** | إجمالي الحساب · الباقي · دفعات · مصروفات · سجل الحركة |
| **المزيد** | خامات · إعدادات · نسخ احتياطي |

---

## القاعدة الأساسية (المالية ↔ الورشة)

1. من **الحسابات → استلام دفعة**: اختر المشروع وسجّل المبلغ.
2. إذا وُجدت دفعات على المشروع → يدخل **قائمة انتظار الورشة**.
3. إذا لم تُسجَّل دفعات → يبقى **مقايسة** في الطلبات فقط.
4. مصروف الورشة يُسجَّل من **الحسابات → مصروفات الورشة** (عام أو مربوط بمشروع) أو من داخل المشروع.

لا حاجة لاختيار «عربون» أو «دفعة عادية» — أي مبلغ مربوط بمشروع يكفي.

---

## قواعد أرقام الحسابات

| المؤشر | ماذا يحسب؟ |
|--------|------------|
| **إجمالي الحسابات** | شغل خد عربون أو دخل ورشة (`انتظار` / `تنفيذ` / `مكتمل`) — **مش** كل المقايسات |
| **الباقي عند العملاء** | شغل مكتمل تصنيعاً فقط — سواء اتسلّم أو لأ |
| **سجل الحركة** | دخول (تحصيل) وخروج (مصروف) بالترتيب |

باقي المشروع داخل صفحة الحساب يبقى `بيع − مدفوع` بدون تغيير.

---

## دورة حياة المشروع

```
مقايسة (الطلبات)
  └── تسجيل دفعة (الحسابات) → قائمة الانتظار
        └── بدء التنفيذ → قيد التنفيذ
              └── إكمال التنفيذ → مكتمل (تسليم منفصل)
```

---

## أين تجد كل وظيفة؟

| المطلوب | الصفحة |
|---------|--------|
| العمل التالي للتنفيذ | **الورشة** |
| أحدث المشاريع / مقايسة / طلب جديد | **الطلبات** |
| استلام فلوس العميل | **الحسابات → استلام دفعة** |
| مدفوع / باقي المشروع | **حساب المشروع** |
| مصروف ورشة (عام أو مشروع) | **الحسابات → مصروفات الورشة → تسجيل مصروف** |
| مصروف من داخل المشروع | **حساب المشروع → مصروفات** أو تبويب المصروفات |
| سجل حركة الفلوس | **الحسابات → سجل الحركة** |
| مشاركة مقايسة / طلبية / تكلفة | **بنود المشروع → المزيد** |
| أسعار الخامات | **المزيد → الخامات** |
| أسعار السبلونات وباقي الاكسسوار | **الخامات → الاكسسوار → النظام → السبلونات / الأسعار** |
| أسعار الحديد | **الخامات → الحديد → الأسعار** |
