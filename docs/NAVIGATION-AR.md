# دليل التنقل — UPVC Design

البرنامج لـ **شركة واحدة فقط**. له **4 أبواب** من الشريط السفلي. كل باب لشغل واحد — مفيش تكرار.

---

## الأبواب الأربعة

| الباب | ماذا يفعل؟ |
|-------|------------|
| **الورشة** | الشغل الحالي + الطابور (عربون) + آخر المشاريع |
| **الطلبات** | المقايسات والعملاء + طلب جديد + استلام عربون |
| **الحسابات** | فواتير · تحصيل · مصروفات · بيانات الشركة |
| **الخامات** | أنظمة وأسعار القطاعات والاكسسوار والزجاج والسلك والحديد |

الإعدادات من أيقونة الترس في الهيدر.

---

## أين تروح لكل حاجة؟

| عايز | روح |
|------|-----|
| تعرف إيه الشغلانة اللي عليها الدور | **الورشة** |
| تعمل مقايسة / طلب جديد | **الطلبات → طلب جديد** |
| تستلم عربون وتجدول | **الطلبات** (أو التحصيل في الحسابات) |
| فلوس وفواتير | **الحسابات** |
| أسعار خامات | **الخامات** |

---

## دورة حياة المشروع

```
مقايسة (في الطلبات)
  └── استلام عربون → تدخل طابور الورشة
        └── ابدأ → في الورشة دلوقتي
              └── تمّ التنفيذ → مكتمل
```

المقايسات من غير عربون **مش** بتظهر في طابور الورشة.

---

## مسار الطلب الجديد

```
طلب جديد
  ├── عميل جديد → مشروع جديد → بنود → رسم
  └── عميل موجود → مشاريع العميل → بنود → رسم
```

| الشاشة | المسار |
|--------|--------|
| الورشة (الرئيسية) | `/` |
| الطلبات | `/orders` |
| طلب جديد | `/design` |
| بنود المشروع | `/design/editor?customer=ID&project=ID` |

---

## نصائح سريعة

1. يوم الشغل؟ **الورشة**.
2. مقايسة جديدة؟ **الطلبات → طلب جديد**.
3. عربون؟ من بطاقة المشروع في **الطلبات** أو **الحسابات → تحصيل → عربون**.
4. فلوس؟ **الحسابات**.
5. أسعار؟ **الخامات**.
