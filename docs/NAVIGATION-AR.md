# دليل التنقل — UPVC Design

البرنامج له **3 أبواب فقط** من الشريط السفلي. كل حاجة تانية فرع من الأبواب دي.

---

## الأبواب الثلاثة

| الباب | ماذا يفعل؟ |
|-------|------------|
| **الرئيسية** | آخر المشاريع + زر «طلب جديد» |
| **الطلبات** | كل العملاء والمشاريع من مكان واحد + «طلب جديد» |
| **الخامات** | أسعار وأنظمة القطاعات والاكسسوار والزجاج والسلك والحديد |

الإعدادات من أيقونة الترس في الهيدر (وحدة القياس، المظهر، ترتيب الأشكال).

---

## مسار الطلب الجديد

```
طلب جديد
  ├── عميل جديد → مشروع جديد → بنود المشروع → الرسم
  └── عميل موجود → مشاريع العميل → (مشروع موجود أو جديد) → بنود → الرسم
```

زر **رجوع** بيرجعك للخطوة اللي قبلها (مش للرئيسية فجأة).

| الشاشة | المسار |
|--------|--------|
| طلب جديد | `/design` |
| عميل جديد | `/design/new-customer` |
| عميل موجود | `/design/customers` |
| مشاريع عميل | `/design/projects?customer=ID` |
| مشروع جديد | `/design/projects/new?customer=ID` |
| بنود المشروع | `/design/editor?customer=ID&project=ID` |
| محرر الرسم | `/design/draw?...&item=ID` |

## مسار الخامات

صفحة الخامات مقسّمة لمجموعتين:

```
الخامات (/materials)
  ├── أنظمة وبراندات
  │     ├── القطاعات → تبويب ١ أسعار البراندات · تبويب ٢ أنظمة القطع → تفاصيل (بيانات / عيدان / تخصيم)
  │     └── الاكسسوار → ١ براندات → ٢ أنظمة → تفاصيل (براندات / مفصلي / جرار / سبلونة)
  └── خامات تانية
        ├── الزجاج → زجاجات + أسعار تدبيل/جورجيا
        ├── السلك → ١ تصنيفات → ٢ أنواع وأسعار
        └── الحديد → أنظمة التسليح
```

**قاعدة سريعة للقطاعات:**
- **البراند** = الأسعار (كم سعر عود الحلق والضلفة)
- **النظام** = التقطيع (العيدان + معادلات التخصيم + ربط البراند)
- الاتنين في صفحة القطاعات بتبويبين — مش صفحتين منفصلتين

**قاعدة سريعة للاكسسوار:**
1. اضبط **البراندات** (قائمة الأسعار)
2. اعمل أو اختَر **نظام**
3. من **تفاصيل** النظام اربط البراند وقواعد الحساب (بالتبويبات)

---

## نصائح سريعة

1. عايز تشتغل على طلب قديم؟ افتح **الطلبات** أو **آخر المشاريع** من الرئيسية.
2. عايز تبدأ من صفر؟ اضغط **طلب جديد**.
3. عايز تعدّل أسعار؟ روح **خامات** من الشريط تحت.
4. الحساب فاضي حالياً — لو فتحت `/profile` هتتحوّل للإعدادات.
