# دليل التنقل — UPVC Design

البرنامج لـ **شركة واحدة فقط**. له **5 أبواب** من الشريط السفلي. كل حاجة تانية فرع من الأبواب دي.

---

## الأبواب الخمسة

| الباب | ماذا يفعل؟ |
|-------|------------|
| **الرئيسية** | آخر المشاريع + زر «طلب جديد» + اختصار الورشة والحسابات |
| **الورشة** | الشغل الحالي + طابور المشاريع اللي استلمنا عليها عربون |
| **الطلبات** | كل العملاء والمشاريع (مقايسات وغيرها) + «طلب جديد» |
| **الحسابات** | فواتير · تحصيل · مصروفات · بيانات الشركة |
| **الخامات** | أنظمة وأسعار القطاعات والاكسسوار والزجاج والسلك والحديد |

الإعدادات من أيقونة الترس في الهيدر (وحدة القياس، المظهر، بيانات الشركة، ترتيب الأشكال).

---

## دورة حياة المشروع (مهم)

```
مقايسة (quote)
  └── استلام عربون → مجدول في طابور الورشة (queued)
        └── بدء التنفيذ → في الورشة (workshop)
              └── تمّ التنفيذ → مكتمل (done)
```

- **مش كل المقايسات بتتنفّذ** — المقايسة تفضل في الطلبات.
- **اللي يدخل الورشة** = المشاريع اللي استلمنا عليها عربون فقط.
- من صفحة **الورشة** تشوف: إيه الشغلانة اللي عليها الدور، الطابور، والشغل الحالي.

---

## مسار الطلب الجديد

```
طلب جديد
  ├── عميل جديد → مشروع جديد → بنود المشروع → الرسم
  └── عميل موجود → مشاريع العميل → (مشروع موجود أو جديد) → بنود → الرسم
```

زر **رجوع** بيرجعك للخطوة اللي قبلها (مش للرئيسية فجأة).

| الشاشة | المسار |
|--------|--------|
| طلب جديد | `/design` |
| عميل جديد | `/design/new-customer` |
| عميل موجود | `/design/customers` |
| مشاريع عميل | `/design/projects?customer=ID` |
| مشروع جديد | `/design/projects/new?customer=ID` |
| بنود المشروع | `/design/editor?customer=ID&project=ID` |
| محرر الرسم | `/design/draw?...&item=ID` |
| الورشة | `/workshop` |

## مسار الحسابات

```
الحسابات (/accounting)
  ├── الفواتير → فاتورة جديدة / تفاصيل فاتورة (+ تحصيل عليها)
  ├── التحصيل → تحصيل جديد (عربون أو عادي — العربون بجدول المشروع)
  ├── المصروفات → مصروف جديد
  └── بيانات الشركة → الاسم · التليفون · الضريبة · السجل
```

رصيد العميل في الطلبات = مجموع الفواتير − مجموع التحصيل (لو فيه حركة محاسبة).

---

## مسار الخامات

```
الخامات (/materials)
  ├── أنظمة الخامات
  │     ├── القطاعات → أنظمة (أسعار المتر + العيدان)
  │     └── الاكسسوار → أنظمة (أسعار + قواعد من التفاصيل)
  └── خامات تانية
        ├── التخصيمات (موحدة: حلق · ضلفة · باكتة · زجاج)
        ├── الزجاج
        ├── السلك
        └── الحديد
```

**القطاعات:** كل نظام فيه أسعاره (سعر المتر من العود) وعيدانه — من «تفاصيل»: بيانات · الأسعار · العيدان.

**التخصيمات:** أرقام موحدة لكل البرنامج لحساب تقديري الخامات — حلق أكبر من الفتحة · ضلفة أصغر · باكتة وزجاج أصغر.

**الاكسسوار:** نظام واحد يكفي — من «تفاصيل»: الأسعار · القواعد · متقدم (اختياري).

---

## نصائح سريعة

1. عايز تعرف إيه الشغلانة اللي عليها الدور؟ **الورشة**.
2. مقايسة جديدة؟ **طلب جديد** — مش هتدخل الورشة غير بعد العربون.
3. طلب قديم؟ **الطلبات** أو **آخر المشاريع**.
4. فلوس العملاء؟ **الحسابات → فواتير / تحصيل** (اختَر نوع «عربون» للجدولة).
5. بيانات شركتك؟ **إعدادات → بيانات الشركة** أو من داخل الحسابات.
6. أسعار القطاعات؟ **خامات → القطاعات → تفاصيل → الأسعار**.
7. مشاركة المشروع PDF؟ من بنود المشروع → أيقونة **مشاركة**.
