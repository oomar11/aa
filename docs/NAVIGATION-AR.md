# دليل التنقل — UPVC Design

البرنامج لـ **شركة واحدة فقط**. الأبواب من الشريط السفلي لكل غرض واحد — دون تكرار.

## الكمبيوتر

افتح **نفس الرابط** من المتصفح على الكمبيوتر:

- قائمة يمين: الرئيسية · الطلبات · الورشة · الحسابات · **الموظفين** · المزيد + **تقارير الربح**
- **الرئيسية** على الكمبيوتر: عنوان وأزرار مدمجة، مؤشرات فلوس كبيرة، ورشة اليوم بأعمدة أغنى، جدول المشاريع ومكسب الشهر
- **الورشة**: الأعمدة جنب بعض — اسحب المشروع بين تنفيذ / انتظار / تسليم، أو اختار من قائمة «انقل». الشغل المتسلّم اللي خلص حسابه مش بيظهر.
- **جوه المشروع** على الكمبيوتر: قائمة جانبية + بنود أوسع + حساب/مصروفات عمودين + رسم بعرض الشاشة
- **الطلبات**: جدول المشاريع (عميل · حالة · بيع · مدفوع · باقي)
- **مصروفات الورشة** على الكمبيوتر: مؤشرات نقدي/آجل + فلتر + جدول + تسجيل جنب السجل + **مصروفات متوقعة** من المقايسة
- **الموظفين** على الكمبيوتر: تبويبات ملخص/حضور/سلف/رواتب + جداول بدل الكروت

الموبايل يفضل الشريط السفلي والكروت زي ما هو.

---

## الأبواب

| الباب | ماذا يفعل؟ |
|-------|------------|
| **الرئيسية** | ملخص اليوم والاختصارات |
| **الطلبات** | العملاء · المقايسات · أحدث المشاريع · طلب جديد |
| **الورشة** | الشغل اليوم: قيد التنفيذ + قائمة الانتظار + التسليم — المتسلّم اللي خلص حسابه يتشال |
| **الحسابات** | إجمالي الحساب · الباقي · دفعات · مصروفات · فلوس برا · متابعات · تقارير · سجل الحركة |
| **المزيد** | خامات · موظفين · إعدادات · نسخ احتياطي |

---

## القاعدة الأساسية (المالية ↔ الورشة)

1. من **الحسابات → استلام دفعة**: اختر المشروع والخزنة وسجّل المبلغ.
2. إذا وُجدت دفعات على المشروع → يدخل **قائمة انتظار الورشة**.
3. إذا لم تُسجَّل دفعات → يبقى **مقايسة** في الطلبات فقط.
4. مصروف الورشة يُسجَّل من **الحسابات → مصروفات الورشة** (عام أو مربوط بمشروع) أو من داخل المشروع.

لا حاجة لاختيار «عربون» أو «دفعة عادية» — أي مبلغ مربوط بمشروع يكفي.

---

## قواعد أرقام الحسابات

| المؤشر | ماذا يحسب؟ |
|--------|------------|
| **إجمالي الحسابات** | شغل خد عربون أو دخل ورشة (`انتظار` / `تنفيذ` / `مكتمل`) — **مش** كل المقايسات |
| **الباقي عند العملاء** | شغل مكتمل تصنيعاً فقط — سواء اتسلّم أو لأ |
| **سجل الحركة** | دخول (تحصيل) وخروج (مصروف) بالترتيب |
| **فلوس لِيا برا** | كل شغل عليه حساب: باقي / اتسلّم / تسليم الشغل |
| **المتابعات** | قال إيه · عمل إيه · وعد بدفع — على العميل أو المشروع |
| **تقارير الربح** | شغل مكتمل واتسلّم حسب تاريخ التسليم: محصّل − مصروف الشغل − المصروف العام في الفترة |

باقي المشروع داخل صفحة الحساب يبقى `بيع − مدفوع` بدون تغيير.

---

## دورة حياة المشروع

```
مقايسة (الطلبات)
  └── تسجيل دفعة (الحسابات) → قائمة الانتظار
        └── بدء التنفيذ → قيد التنفيذ
              └── إكمال التنفيذ → مكتمل (تسليم منفصل)
```

---

## أين تجد كل وظيفة؟

| المطلوب | الصفحة |
|---------|--------|
| العمل التالي للتنفيذ | **الورشة** |
| أحدث المشاريع / مقايسة / طلب جديد | **الطلبات** |
| استلام فلوس العميل | **الحسابات → استلام دفعة** |
| فلوس لِيا برا / اتسلّم ولا لأ | **الحسابات → فلوس لِيا برا** |
| قال إيه / عمل إيه | **الحسابات → المتابعات** أو **حساب المشروع → المتابعة** |
| بتكسب ولا لأ | **الحسابات → تقارير الربح** |
| مدفوع / باقي المشروع | **حساب المشروع** |
| مصروف ورشة (عام أو مشروع) | **الحسابات → مصروفات الورشة → تسجيل مصروف** |
| موظفين / حضور / سلف | **المزيد → الموارد البشرية** |
| صرف راتب (مصروف أجور) | **المزيد → الموظفين → صرف الرواتب** أو **الحسابات → رواتب الموظفين** |
| تعيين عمال على شغلانة | **الورشة** أو **إعدادات المشروع** أو **حساب المشروع** |
| مصروف من داخل المشروع | **حساب المشروع → مصروفات** أو تبويب المصروفات |
| سجل حركة الفلوس | **الحسابات → سجل الحركة** |
| مشاركة مقايسة / أمر تشغيل / طلبية / تكلفة | **بنود المشروع → المزيد** |
| أسعار الخامات | **المزيد → الخامات** |
| أسعار السبلونات وباقي الاكسسوار | **الخامات → الاكسسوار → النظام → السبلونات / الأسعار** |
| أسعار الحديد | **الخامات → الحديد → الأسعار** |
