# دليل التنقل — UPVC Design

البرنامج لـ **شركة واحدة فقط**. له **4 أبواب** من الشريط السفلي. كل باب لغرض واحد — دون تكرار.

---

## الأبواب الأربعة

| الباب | ماذا يفعل؟ |
|-------|------------|
| **الورشة** | العمل الحالي + قائمة الانتظار (عربون) + أحدث المشاريع |
| **الطلبات** | المقايسات والعملاء + طلب جديد + تسجيل عربون |
| **الحسابات** | فواتير · تحصيل · مصروفات · بيانات الشركة |
| **الخامات** | أنظمة وأسعار القطاعات والاكسسوار والزجاج والسلك والحديد |

الإعدادات من أيقونة الترس في الهيدر.

---

## أين تجد كل وظيفة؟

| المطلوب | الصفحة |
|---------|--------|
| معرفة العمل التالي للتنفيذ | **الورشة** |
| إنشاء مقايسة / طلب جديد | **الطلبات → طلب جديد** |
| تسجيل عربون وإضافة إلى قائمة الانتظار | **الطلبات** (أو التحصيل في الحسابات) |
| الفواتير والمدفوعات | **الحسابات** |
| أسعار الخامات | **الخامات** |

---

## دورة حياة المشروع

```
مقايسة (في الطلبات)
  └── تسجيل عربون → قائمة انتظار الورشة
        └── بدء التنفيذ → قيد التنفيذ
              └── إكمال التنفيذ → مكتمل
```

المقايسات دون عربون **لا** تظهر في قائمة انتظار الورشة.

---

## مسار الطلب الجديد

```
طلب جديد
  ├── عميل جديد → مشروع جديد → بنود → رسم
  └── عميل موجود → مشاريع العميل → بنود → رسم
```

| الشاشة | المسار |
|--------|--------|
| الورشة (الرئيسية) | `/` |
| الطلبات | `/orders` |
| طلب جديد | `/design` |
| بنود المشروع | `/design/editor?customer=ID&project=ID` |

---

## نصائح سريعة

1. لمتابعة العمل اليومي: **الورشة**.
2. لمقايسة جديدة: **الطلبات → طلب جديد**.
3. لتسجيل العربون: بطاقة المشروع في **الطلبات** أو **الحسابات → تحصيل → عربون**.
4. للمالية: **الحسابات**.
5. للأسعار: **الخامات**.
