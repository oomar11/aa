# دليل التنقل — UPVC Design

البرنامج لـ **شركة واحدة فقط**. له **4 أبواب** من الشريط السفلي. كل باب لغرض واحد — دون تكرار.

---

## الأبواب الأربعة

| الباب | ماذا يفعل؟ |
|-------|------------|
| **الورشة** | الشغل اليوم فقط: قيد التنفيذ + قائمة الانتظار |
| **الطلبات** | العملاء · المقايسات · أحدث المشاريع · طلب جديد |
| **الحسابات** | استلام الدفعات · الفواتير · سجل المصروفات |
| **الخامات** | أسعار القطاعات والاكسسوار والزجاج والسلك والحديد |

---

## القاعدة الأساسية (المالية ↔ الورشة)

1. من **الحسابات → استلام دفعة**: اختر المشروع وسجّل المبلغ.
2. إذا وُجدت دفعات على المشروع → يدخل **قائمة انتظار الورشة**.
3. إذا لم تُسجَّل دفعات → يبقى **مقايسة** في الطلبات فقط.
4. مصروف المشروع يُسجَّل **من داخل المشروع فقط** (بنود المشروع → المزيد → مصروفات المشروع).

لا حاجة لاختيار «عربون» أو «دفعة عادية» — أي مبلغ مربوط بمشروع يكفي.

---

## دورة حياة المشروع

```
مقايسة (الطلبات)
  └── تسجيل دفعة (الحسابات) → قائمة الانتظار
        └── بدء التنفيذ → قيد التنفيذ
              └── إكمال التنفيذ → مكتمل
```

---

## أين تجد كل وظيفة؟

| المطلوب | الصفحة |
|---------|--------|
| العمل التالي للتنفيذ | **الورشة** |
| أحدث المشاريع / مقايسة / طلب جديد | **الطلبات** |
| استلام فلوس العميل | **الحسابات → استلام دفعة** |
| الفواتير والمتبقي | **الحسابات → الفواتير** |
| مصروف على مشروع | **بنود المشروع → المزيد → مصروفات المشروع** |
| سجل كل المصروفات | **الحسابات → سجل المصروفات** (عرض فقط) |
| مشاركة مقايسة / طلبية / تكلفة | **بنود المشروع → المزيد** |
| أسعار الخامات | **الخامات** |
| أسعار السبلونات وباقي الاكسسوار | **الخامات → الاكسسوار → النظام → السبلونات / الأسعار** |
| أسعار الحديد | **الخامات → الحديد → الأسعار** |
