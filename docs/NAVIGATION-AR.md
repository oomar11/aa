# دليل التنقل — UPVC Design

هذا الدليل يشرح هيكل البرنامج بطريقة بسيطة. البرنامج مقسّم لـ **3 أقسام رئيسية** فقط.

---

## الأقسام الثلاثة

| القسم | من أين؟ | ماذا يفعل؟ |
|-------|---------|------------|
| **التصميم** | الرئيسية → بدء التصميم | إنشاء طلب: عميل → مشروع → بنود → رسم |
| **الطلبات** | الرئيسية → الطلبات | تصفح العملاء والمشاريع والإجماليات |
| **الخامات** | الرئيسية → خامات | إدارة أسعار القطاعات والاكسسوار والزجاج والسلك والحديد |

---

## مسار التصميم (الأهم)

```
الرئيسية
  └── بدء التصميم (/design)
        ├── عميل جديد → إدخال بيانات
        └── قاعدة العملاء → اختيار عميل
              └── مشاريع العميل
                    ├── مشروع جديد
                    └── اختيار مشروع
                          └── قائمة البنود (شبابيك/أبواب)
                                ├── إضافة من تمبلت
                                └── فتح محرر الرسم لكل بند
                                      ├── رسم وتقسيم (سوقاس)
                                      ├── خصائص الضلفة (فتح، سلك، زجاج)
                                      └── شريط الخامات (حساب التكلفة)
```

### روابط التصميم

| الشاشة | المسار |
|--------|--------|
| بداية طلب جديد | `/design` |
| عميل جديد | `/design/new-customer` |
| قاعدة العملاء | `/design/customers` |
| مشاريع عميل | `/design/projects?customer=ID` |
| مشروع جديد | `/design/projects/new?customer=ID` |
| قائمة البنود | `/design/editor?customer=ID&project=ID` |
| محرر الرسم | `/design/draw?customer=ID&project=ID&item=ID` |
| إعدادات المشروع | `/design/project-settings?customer=ID&project=ID` |

---

## مسار الخامات

```
الخامات (/materials)
  ├── قطاعات → أنظمة البروفيل + براندات + تفاصيل كل سيستم
  ├── اكسسوار → أنظمة + براندات + قواعد المفصلي/الجرار
  ├── زجاج → كتالوج الزجاجات والتدبيل
  ├── سلك → تصنيفات وأنواع السلك
  └── حديد → تسليح الحلق والضلفة
```

كل بند تصميم يرث الخامات الافتراضية من المشروع، ويمكن تخصيصها لكل بند على حدة.

## هيكل المجلدات في الكود

```
app/                    ← صفحات التطبيق (روابط فقط — بدون منطق معقد)
components/
  layout/               ← الهيدر، التنقل، الغلاف الموحد (AppShell)
  home/                 ← شاشة الرئيسية
  design/               ← قائمة البنود، المعاينة، التمبلتات
  drawing/              ← محرر الرسم (الكانفس، الأدوات، الخامات)
  materials/            ← محررات الخامات والبراندات
  customers/            ← العملاء والمشاريع
  orders/               ← متصفح الطلبات
  settings/             ← الثيم والوحدات
lib/
  routes.ts             ← كل الروابط في مكان واحد
  storage/keys.ts       ← مفاتيح التخزين المحلي
  material-systems.ts   ← كتالوج الخامات (أنواع + أسعار + حفظ)
  materials.ts          ← حساب تكلفة الخامات لكل بند
  design-items.ts       ← نموذج البند والتسعير
  window-layout.ts      ← شجرة التقسيم (سوقاس/ضلف)
  window-templates.ts   ← تمبلتات الأشكال (~80 شكل)
  drawing-ops.ts        ← عمليات الرسم (تقسيم، حذف، تساوي)
```

## أين تُحفظ البيانات؟

كل البيانات في **localStorage** على جهازك (بدون سيرفر):

| المفتاح | المحتوى |
|---------|---------|
| `upvc-customers` | العملاء المُنشَأون |
| `upvc-projects` | المشاريع |
| `upvc-project-items` | بنود التصميم |
| `upvc-material-systems` | كتالوج الخامات والأسعار |
| `upvc-theme` | الوضع الفاتح/الداكن |
| `upvc-unit` | وحدة القياس (مم/سم) |
| `upvc-template-order` | ترتيب التمبلتات |

---

## نصائح للتنقل

1. **ابدأ دائماً من الرئيسية** — 3 أزرار فقط: تصميم، طلبات، خامات.
2. **التصميم يمشي بترتيب**: عميل → مشروع → بند → رسم.
3. **الخامات تُعدّ مرة واحدة** — ثم تُستخدم تلقائياً في كل التصميمات.
4. **زر الرجوع** في أعلى كل شاشة يرجعك للخطوة السابقة.
5. **شريط التنقل السفلي**: الرئيسية والملف الشخصي.
