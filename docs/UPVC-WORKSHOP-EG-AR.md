# تصنيع UPVC واكسسوار الورشة في مصر

مرجع دائم لفريق المنتج والكود. القواعد هنا هي **مصدر الحقيقة** لحساب الاكسسوار والقطاعات في البرنامج بعد تصحيح أغسطس 2026.

## سلسلة التصنيع

```
قطاعات → قص وتخصيم → لحام → اكسسوار → زجاج/سلك → تشطيب وتسليم
```

| المرحلة | ماذا يحدث | أين في البرنامج |
|---------|-----------|------------------|
| خامات القطاعات | أنظمة حلق/ضلفة/سقاس/باكتة وأسعار العيدان + أطقم | المزيد ← الخامات ← القطاعات |
| اكسسوار | فورنا/كالي وغالباً تركي: سبلونة، سكاك، مقابض، مفصلات، مجموعة قلاب، عجل، فرش | المزيد ← الخامات ← الاكسسوار |
| حديد | تراك وتسليح | الخامات ← الحديد |
| رسم البند | تقسيم الضلف + فتح + بارز/غاطس + بوكلير | محرر الرسم |
| مقايسة | بيع من تكلفة خامات + تسعير هجين | بنود المشروع / PDF |
| ورشة | بعد الدفعة: انتظار → تنفيذ → تسليم | باب الورشة |

## قاموس المصطلحات

| المصطلح | المعنى العملي |
|---------|----------------|
| **سبلونة** | شريط قفل متعدد النقاط على حافة الضلفة؛ المقاس بالسم ويُختار حسب ارتفاع الضلفة ناقص فرق (افتراضي ٢٠٠ مم) — نفس القطعة للمفصلي والقلاب |
| **سكاك مفصلي** | قطع التسكيك على الحلق للضلفة المفصلية والقلاب — اسم واحد، العدد من مقاس السبلونة |
| **سكاك كورنر سفلي** | تسكيك كورنر مجموعة القلاب (مش «سكاك قلاب» عام) |
| **كورنر علوي / سفلي** | زوايا مجموعة المفصلي القلاب |
| **سكاك جرار** | تسكيك الجرار على الحلق — اسم واحد، العدد من مقاس السبلونة |
| **سكاك بوكلير** | تسكيك خاص بزوج مفصلي بينهما بوكلير (مش «لقمة») |
| **سكاك ترباس** | تسكيك الترباس على البوكلير |
| **مفصلة** | قطعة مفصلة عادية واحدة للشباك والباب — الفرق العدد فقط |
| **مفصلة علوية جزء الضلفة** | قطعة من مجموعة T&T (9 أو 13 axis) — مش للمفصلي العادي |
| **ذراع قلاب** | ذراع القلاب بمقاسات رينج حسب عرض الضلفة (مثل 350-600) |
| **مقبض غاطس** | على ضلفة الجرار **الغاطسة** |
| **مقبض بارز** | على ضلفة الجرار **البارزة**، وأيضاً على المفصلي/البوكلير |
| **بارز / غاطس** | ترتيب تداخل ضلف الجرار؛ الافتراضي يتناوب في الصف |
| **بوكلير** | قطاع ثابت بين ضلفتين مفصليتين متقابلتين |
| **طبة بوكلير** | طقم/قطعة بارتفاع الضلفة لكل بوكلير صالح — قطاع/تكلفة قطاعات، مش سكاك |
| **سقاس مفصلي** | قائم/عارضة تقسيم في الحلق أو جوا ضلفة مفصلي |
| **سقاس جرار** | قائم/عارضة تقسيم جوا ضلفة الجرار فقط |
| **طقم تجميع سقاس مفصلي** | طقم ميكانيكي **١ لكل سقاس مفصلي** |
| **طقم تجميع سقاس جرار** | طقم ميكانيكي **١ لكل سقاس جرار** |
| **سلك · كتلة واحدة** | صنف سلك تتجمع فيه الضلف المتجاورة لمساحة/قطاع واحد بدل كل ضلفة لوحدها |
| **فرش** | فرشة عزل محيط ضلفة الجرار + ارتفاع السكينة |
| **عجل** | عجلات الجرار (افتراضي ٢ لكل ضلفة) |
| **سكينة تقابل** | قطاع تداخل الضلف في أنظمة الجرار (مش اكسسوار فورنا) |
| **اكس / Axis** | مقاس مجرى الاكسسوار (مثلاً ٩ مم) — القطع لازم تطابق القطاع |

## أنظمة الفتح ≠ نظام اكسسوار واحد

| النظام | الفتح | اكسسوار نموذجي |
|--------|--------|----------------|
| **مفصلي عادي** | ضلفة بتفتح جنب | مفصلات عادية + سبلونة مفصلي + سكاك + مقبض |
| **مفصلي قلاب (T&T)** | فتح كامل + قلب علوي | **مجموعة بريمير كاملة** لكل ضلفة |
| **قلاب فقط** | قلب علوي | **نفس المجموعة الكاملة** |
| **جرار** | ضلف على تراك | عجل + فرش + سبلونة جرار + سكاك جرار + مقبض غاطس/بارز |
| **باب مفصلي** | باب | **نفس المفصلة العادية** بعدد أكبر + كالون + مقبض إشارة + وش تسكيك |

### قاعدة المفصلات

- **مفصلة الشباك والباب = قطعة واحدة** (فئة براند `hinge`)
- شباك مفصلي عادي: عادة **٢ لكل ضلفة** (`hingesPerSash`)
- باب: **٣ أو ٤ لكل ضلفة** (`hingesPerDoor`)
- **مفصلة علوية اكس 9** فئة قلاب منفصلة — لا تُحسب كافتراضي للمفصلي العادي

## قواعد BOM المعتمدة

### جرار ٤ ضلفة (بارز-غاطس-بارز-غاطس)

- عجل: ٢ × ٤ = ٨
- سبلونة جرار: ١ لكل ضلفة (المقاس من الارتفاع − فرق السبلونة)
- **سكاك جرار:** لكل ضلفة = `slidingLockQty` لمقاس سبلونتها
- **مقبض غاطس:** ١ × عدد الضلف الغاطسة → عادة **٢**
- **مقبض بارز:** ١ × عدد الضلف البارزة → عادة **٢**
- فرش: حسب المحيط والسكينة

### مفصلي عادي (ضلفة واحدة أو أكثر — فتح casement)

- **مفصلات عادية** حسب `hingesPerSash` (عادة ٢)
- سبلونة مفصلي + **سكاك مفصلي** = `hingedLockQty` لمقاس السبلونة
- مقبض بارز حسب الإعداد
- **لا** مفصلة علوية اكس 9 ولا ذراع قلاب

### مفصلي ضلفتين + بوكلير (فتح مفصلي عادي)

- سبلونة واحدة للزوج (من أطول ضلفة) — **مش سبلونتين**
- **سكاك بوكلير** (بدل سكاك المفصلي — بدون لقمة)
- ترباس + سكاك ترباس
- مقبض بارز
- **طبة بوكلير:** كمية ١ لكل بوكلير مكتشف بين ضلفتين متقابلتين
- مفصلات عادية لكل ضلفة في الزوج

### قلاب (فتح tilt / tilt-turn)

لكل ضلفة قلاب:

- **سبلونة مفصلي عادي** (نفس جدول المفصلي حسب **ارتفاع** الضلفة) + سكاك مفصلي
- **ذراع قلاب** (رينج حسب **عرض** الضلفة)
- كورنر علوي + كورنر سفلي
- مفصلة علوية جزء الضلفة + جزء الحلق
- مفصلة سفلية جزء الحلق + جزء الضلفة
- مفصلة علوية بنز
- سكاك كورنر سفلي
- أغطية مفصلات (افتراضي ٤)
- مقبض بارز
- **لا** سبلونة قلاب مخصوصة منفصلة عن المفصلي العادي
- الأبواب لا تدخل هنا

### باب مفصلي

- **نفس المفصلة العادية** بعدد `hingesPerDoor` (٣ أو ٤)
- كالون + مقبض إشارة + وش تسكيك — بدون سبلونة/سكاك مفصلي شباك

### سقاس

- **سوقاس مفصلي:** متر + طقم تجميع سقاس مفصلي = ١ لكل سقاس (تقسيم حلق/ضلفة مفصلي)
- **سوقاس جرار:** متر + طقم تجميع سقاس جرار = ١ لكل سقاس (**تقسيم جوا ضلفة الجرار فقط** — مش بين الضلف)
- **بين ضلف الجرار:** سكينة واحدة لكل ضلفة متحركة (ارتفاع الضلفة) — مش سوقاس
- مفصلي×جرار عند التقسيم يبقى **كوبلن** (مش سقاس)

## عدد السكاك حسب مقاس السبلونة

كل صف في كتالوج السبلونة يحمل:

- `hingedLockQty` — سكاك مفصلي لهذا المقاس
- `slidingLockQty` — سكاك جرار لهذا المقاس

(سبلونة/مقص القلاب لهم كتالوج رينج منفصل — مش صفوف السبلونة المشتركة.)

القيم الابتدائية قابلة للتعديل من شاشة الاكسسوار ← السبلونات. الافتراضي التقريبي:

| مقاس سم | سكاك (مفصلي/جرار) |
|---------|-------------------|
| ٣٠–٤٠ | ١ |
| ٦٠–٨٠ | ٢ |
| ١٠٠–١٢٠ | ٣ |
| ١٤٠–١٦٠ | ٤ |
| ١٨٠–٢٠٠ | ٥ |

## أخطاء سابقة تم تصحيحها

1. الجرار كان يحسب مقبض غاطس فقط → أصبح غاطس + بارز.
2. أسماء وهمية: سكة وسط / سكة وسط جرار / لقمة بوكلير → سكاك مفصلي / سكاك جرار / سكاك بوكلير.
3. عدد السكاك كان ثابتاً لكل سبلونة → مربوط بمقاس السبلونة.
4. طبة البوكلير كانت تختفي من التكلفة عند سعر صفر → تظهر بالكمية حتى بدون سعر.
5. براند المفصلات الافتراضي كان «مفصلة علوية 9 axis» على المفصلي العادي → صار مفصلة عادية؛ الاكس 9 لفئة القلاب.
6. فتح القلاب كان يُحسب كمفصلي عادي بالكامل → BOM قلاب منفصل.
7. طقم تجميع السقاس كان غائباً → ١ لكل سقاس على نظام القطاعات.
8. السقاس كان موحّداً → انفصل مفصلي/جرار بأمتار وأطقم تجميع منفصلة.
9. فتح القلاب يستخدم **سبلونة المفصلي العادي** + **ذراع قلاب** (مش سبلونة قلاب مخصوصة).
10. «سكاك قلاب» وهمي → **سكاك مفصلي** من جدول السبلونة + **سكاك كورنر سفلي** مع مجموعة القلاب.
11. زوج البوكلير كان ياخد سكاك مفصلي مع سكاك البوكلير → سكاك بوكلير فقط + سبلونة واحدة.
12. خط التقسيم بين ضلف جرار كان يتحسب سوقاس جرار → سكينة لكل ضلفة؛ سوقاس الجرار من التقسيم جوا الضلفة فقط.

## مصادر سوق مصر (مرجع)

- كتالوجات قطاعات محلية (أمان PVC، Premier سيتي، كرافت الين / Kraft Allen، كومبن، نيولاين…).
- اكسسوار تركي شائع: Vorne / Kale — سبلونات بمقاسات سم وأسعار للمقاس.
- **قائمة أسعار الاكسسوارات بريمير يوليو 2026**: مصدر أسعار مجموعة المفصلي القلاب T&T.
- ورش مصر: نفس مسار القص → لحام → اكسسوار → زجاج.

عند تعارض بين كتالوج مورّد وهذا الملف، **قواعد الورشة في هذا المستند هي المعتمدة في البرنامج** إلى أن يُحدَّث الملف صراحة.
